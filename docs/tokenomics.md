# Tokenomics

**Current status: no token has been announced.** There is no contract address, supply, allocation, sale or listing. The contract slot on the website stays inert until an address is formally stated, and this file will change only when that happens.

If you see a token, presale or airdrop claiming to be Secuty before this file says otherwise, treat it as unverified.

## Why this file exists

Publishing the rules for how a token would be described, before any token exists, lets the community hold the project to them.

## Commitments before any announcement

When and if a token is introduced, the project commits to publish the following together, in this repository, before or at the same moment as the address:

1. **Contract address** on Robinhood Chain (chain ID 4663), added to the website's records as `stated`.
2. **Source and verification.** Verified source code and the compiler settings used.
3. **Supply and allocation.** Total supply and the full split, with every wallet that holds a non-public share.
4. **Vesting.** Start dates, cliffs and release schedules for team and early contributors, enforced onchain where possible.
5. **Utility.** What the token does inside the protocol, in plain terms, and what it does not do.
6. **Audit.** The independent review covering the token contract.
7. **Risks.** A plain list of what could go wrong, including regulatory and market risk.

## Candidate utility areas (not decided)

These are design directions under discussion, not features:

- Staking by contributors to the shared watchlist, with penalties for bad submissions.
- Fee settlement for screening or agent-rail services.
- Governance over watchlist rules and disputes.

None of these requires a token to exist for the protocol to function. The wallet, rulebook and signing modules are designed to work without one.

## What will not happen

- No hidden allocation.
- No unannounced mint authority. Any mint or pause right will be listed with its holder and limits.
- No claim of returns, yield or price targets in project materials.

## Not financial advice

Nothing here is investment advice or an offer of securities. Do your own research and never rely on a post that has not been reflected in this file and on <https://secuty.xyz>.
