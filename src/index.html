Request path

Four stops.
No shortcuts.

Machines act faster than people can watch. So nothing reaches the chain on a hunch: a request is declared, screened, authorized by fixed rules and only then signed.

Declare

A person, or an AI agent holding a narrow key, says what it wants to do.

Screen

The request is replayed in private to learn which assets move and which permissions change.

Authorize

Fixed limits and lists answer yes, no, or "show me stronger proof".

Sign

Cleared requests are signed and sent. Big-ticket ones demand a quantum-resistant signature.
